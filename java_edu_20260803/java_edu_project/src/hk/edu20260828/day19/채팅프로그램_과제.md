# 과제명: 멀티스레드 기반 다중 채팅 프로그램 구현

## 1. 과제 목적
자바 네트워크 프로그래밍(TCP 소켓 통신) 및 멀티스레드, 동기화(Synchronization), I/O 스트림에 대한 이해도를 종합적으로 평가하기 위함. 단일 접속 서버를 확장하여 여러 클라이언트가 동시에 접속해 메시지를 주고받을 수 있는 다중 채팅 서버 및 클라이언트를 구현한다.

## 2. 구현 명세 및 요구사항

### 2.1 서버 시스템 (D3_ChatServer.java)
- **포트 바인딩 및 연결 대기**
  - 특정 포트(예: 12345)로 ServerSocket을 생성하고 클라이언트의 연결을 지속적으로 대기(accept)해야 한다.
- **클라이언트 핸들러 스레드 구현**
  - 다중 접속 처리를 위해 클라이언트 연결 시마다 해당 통신을 전담하는 스레드(ClientHandler)를 생성하여 병렬 처리해야 한다.
- **접속자 세션 관리 및 동기화**
  - 현재 접속 중인 클라이언트들의 출력 스트림(PrintWriter)을 Set 또는 List 등의 컬렉션으로 관리해야 한다.
  - 여러 스레드가 동시에 해당 컬렉션에 접근할 수 있으므로, 반드시 synchronized 블록을 사용하여 동기화 처리를 적용해야 한다.
- **메시지 브로드캐스팅(Broadcasting)**
  - 특정 클라이언트로부터 수신된 메시지는 컬렉션에 저장된 모든 클라이언트에게 전송되어야 한다.
  - 최초 수신된 메시지는 해당 사용자의 '대화명(ID)'으로 처리하며, 이후 수신되는 메시지는 `[대화명] 메시지내용` 형태로 포맷팅하여 전송한다.
- **자원 반환 및 예외 처리**
  - 클라이언트 접속 종료 또는 예외 발생 시, 접속자 컬렉션에서 해당 클라이언트를 안전하게 제거하고 소켓 자원을 반환해야 한다.

### 2.2 클라이언트 시스템 (D3_ChatClient.java)
- **서버 접속 및 I/O 스트림 초기화**
  - 서버 IP(localhost) 및 지정된 포트로 Socket 연결을 수행한다.
  - 한글 인코딩 문제 방지를 위해 네트워크 송수신 스트림은 UTF-8로 설정하고, 콘솔 입력 스트림(System.in)은 운영체제 환경에 맞춰 설정(예: MS949)한다.
- **대화명 입력 및 전송**
  - 프로그램 실행 시 대화명을 콘솔로부터 입력받고, 이를 서버로 최초 1회 전송한다.
- **수신 스레드 분리**
  - 사용자의 키보드 입력과 무관하게 서버로부터 수신되는 메시지를 실시간으로 콘솔에 출력해야 하므로, 수신 전용 스레드를 별도로 구현하여 실행해야 한다.
- **메시지 송신**
  - 메인 스레드는 반복문을 통해 콘솔 입력을 지속적으로 읽어 들이고, 이를 서버로 전송한다.

## 3. 개발 유의사항
- **리소스 자동 해제:** try-with-resources 구문을 적극 활용하여 Socket, BufferedReader, PrintWriter 등의 입출력 자원 누수가 발생하지 않도록 코드를 작성할 것.
- **버퍼 플러시(Flush):** PrintWriter 객체 생성 시 autoFlush 속성을 true로 설정하거나, 전송 시 수동으로 flush() 메서드를 호출할 것.
- **예외 처리:** 네트워크 단절 등 예기치 않은 오류 발생 시 프로그램이 비정상 종료되지 않고 적절한 예외 처리(try-catch)가 이루어지도록 구현할 것.
