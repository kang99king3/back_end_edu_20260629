# 다중 채팅 프로그램(채팅방) 단계별 구현 가이드

이 문서는 여러분이 다중 접속 채팅 서버와 클라이언트를 순서대로 완성할 수 있도록 돕는 실습 가이드입니다. 아래의 단계를 하나씩 따라가며 코드를 완성해 보세요.

---

## [1부] 다중 채팅 서버 구현하기 (`D3_ChatServer.java`)

### Step 1. 서버 기본 구조 만들기
- `D3_ChatServer` 클래스를 생성하고 `main` 메서드를 만듭니다.
- 서버 통신에 사용할 포트 번호(예: `12345`)를 상수로 정의하세요.

### Step 2. 접속자 명단(Set) 준비하기
- 여러 클라이언트가 보내는 메시지를 모두에게 전달(Broadcasting)하려면, 현재 접속 중인 클라이언트들의 리스트를 서버가 기억하고 있어야 합니다.
- `main` 메서드 외부에 `static Set<PrintWriter> clients = new HashSet<>();` 객체를 생성하세요. (여러 스레드들이 이 명단을 공유해야 하므로 static으로 선언합니다.)

### Step 3. 서버 소켓 생성 및 클라이언트 접속 대기
- `try-with-resources` 문법을 사용하여 `ServerSocket serverSocket = new ServerSocket(포트번호)`를 생성하세요.
- `while (true)` 무한 루프를 만들고, 루프 안에서 `serverSocket.accept();`를 호출하여 손님(클라이언트)의 접속을 기다립니다.
- 접속이 성공하면 해당 클라이언트와 통신할 전용 `Socket` 객체를 반환받습니다.

### Step 4. 클라이언트 전담 알바생(스레드) 클래스 만들기
- 메인 스레드는 계속해서 새로운 손님(accept)을 받아야 하므로, 개별 클라이언트와의 채팅 통신은 새로운 스레드에게 맡겨야 합니다.
- `D3_ChatServer` 클래스 내부에 `static class ClientHandler extends Thread` 내부 클래스를 작성하세요.
- 이 스레드는 생성자를 통해 방금 연결된 클라이언트의 `Socket`을 전달받아 자신의 필드에 저장해 두어야 합니다.

### Step 5. 스레드의 핵심 업무 (run 메서드 구현)
- `ClientHandler`의 `run()` 메서드를 오버라이딩합니다.
- 전달받은 `Socket`을 `try-with-resources` 소괄호 안에 등록하고(`Socket autoCloseSocket = socket;`), 이 소켓으로부터 메시지를 주고받을 `BufferedReader in`과 `PrintWriter out` 스트림을 생성하세요.
  - *(주의: `PrintWriter` 생성 시 두 번째 인자를 `true`로 주어 auto-flush를 반드시 활성화하세요.)*

### Step 6. 명단 등록 및 단체 메시지 전송(Broadcasting) 구현
- 스트림이 생성되면 가장 먼저 `clients.add(out);`을 호출하여 명단에 자신을 등록합니다. 
  - *(필수: 여러 스레드가 명단에 동시 접근하여 에러가 나지 않도록 반드시 `synchronized (clients)` 블록 안에서 수행해야 합니다.)*
- 첫 번째로 날아오는 메시지(`in.readLine()`)를 읽어 **'대화명(ID)'** 변수에 저장하세요.
- 이후 `while ((message = in.readLine()) != null)` 문을 돌며 클라이언트가 보내는 메시지를 무한히 읽어들입니다.
- 메시지를 받으면 다시 `synchronized (clients)` 블록을 열고, 향상된 for문을 사용해 `clients` 명단에 있는 모든 사람의 `PrintWriter`를 꺼내어 `[대화명] 메시지` 형태로 전송(`println`)합니다.

### Step 7. 퇴장 처리 (finally)
- 클라이언트가 채팅을 종료하거나 연결이 끊어지면 에러가 발생하며 `run()` 메서드가 끝나게 됩니다. 
- `finally` 블록을 만들고, 명단에서 본인의 `out` 객체를 제거(`clients.remove(out);`)하여 다른 클라이언트들에게 유령 메시지가 전송되지 않도록 깔끔하게 지워주세요.

## [2부] 다중 채팅 클라이언트 구현하기 (`D3_ChatClient.java`)

### Step 1. 서버 접속 및 스트림 생성
- `main` 메서드에서 `try-with-resources`를 사용하여 `Socket socket = new Socket("localhost", 12345);`를 생성합니다.
- 서버와 통신할 `PrintWriter out`과 `BufferedReader in` 스트림을 만듭니다. (네트워크 한글 깨짐 방지를 위해 인코딩을 `"UTF-8"`로 지정하세요)
- 내 키보드 입력을 읽어들일 `BufferedReader stIn = new BufferedReader(new InputStreamReader(System.in, "MS949"));`도 함께 생성합니다.

### Step 2. 대화명(ID) 설정 및 전송
- 화면에 "사용할 ID(대화명)를 입력하세요: "를 출력합니다.
- `stIn.readLine()`으로 키보드 입력을 받아 변수에 저장한 뒤, `out.println()`을 통해 서버로 제일 먼저 전송하세요.

### Step 3. 수신 전용 스레드 분리 (매우 중요)
- 내가 키보드를 치는 동안에도 서버에서 오는 다른 사람의 메시지가 실시간으로 화면에 출력되어야 합니다.
- 수신을 전담할 클래스 `class IncomingMessagesHandler implements Runnable` (또는 `extends Thread`)를 작성하세요.
- 이 스레드는 생성자로 서버 수신용 `BufferedReader in`을 전달받습니다.
- `run()` 메서드 안에서 `while (true)`를 돌며 `in.readLine()`으로 서버 메시지를 읽고 곧바로 화면(`System.out.println`)에 출력합니다.
- 메인 메서드에서 이 스레드 객체를 생성하고 `start()` 시켜 수신 업무를 시작하세요.

### Step 4. 메시지 송신 (메인 스레드)
- 수신 스레드를 백그라운드에서 실행시켰다면, 메인 스레드는 이제 키보드 입력만 신경 쓰면 됩니다.
- `while ((userInput = stIn.readLine()) != null)` 반복문을 작성합니다.
- 사용자가 키보드로 입력한 `userInput`을 `out.println(userInput);`을 통해 서버로 전송합니다.
